12. SCIENTIFIC COLLOCATION
--------------------------

The model and observation datasets will not necessarily
have identical:

- Latitude
- Longitude
- Time
- Depth

Therefore, model–observation comparison must perform
appropriate spatial, temporal and vertical collocation.

Conceptually:

Model location/time/depth
          ↕
Collocation
          ↕
Observation location/time/depth
          ↓
Model − Observation
          ↓
Error


13. MODEL–OBSERVATION COMPARISON
--------------------------------

For each matched observation, the system may calculate:

Bias:
Model − Observation

Absolute error:
|Model − Observation|

RMSE:
sqrt(mean((Model − Observation)^2))

The system should retain information about the
collocation method used for each comparison.


14. IMPORTANT SCIENTIFIC NOTES
------------------------------

1. This dataset is MODEL DATA, not in-situ observation data.

2. INCOIS HYCOM provides the predicted/model component
   of the Operational Mode.

3. Argo observations provide the observational component.

4. Model and observation values should not be compared
   solely because they occur on the same calendar day.

5. Spatial, temporal and vertical differences must be
   considered during collocation.

6. The model depth levels are unevenly spaced:

   0
   17.5
   52.5
   125
   275
   500 m

7. TEMP and SALN do not contain explicit unit attributes
   in this downloaded NetCDF file.

8. UVEL and VVEL explicitly contain units of m/s.

9. Lack of an explicit unit attribute for TEMP or SALN
   does not mean the variable has no unit. The unit should
   be verified from the official product documentation.

10. The downloaded file should be treated as the original
    scientific input and should not be manually edited.
